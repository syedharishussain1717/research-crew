# 🔎 AI Research Team (CrewAI + Groq + Streamlit)

Four AI agents work one after another to research a topic and write a report:
Research Planner, Web Researcher, Research Analyst, Report Writer.

## Setup
1. Upload all files to a GitHub repository (keep the folder structure).
2. On Streamlit Community Cloud create an app from the repo, main file `app.py`,
   Python version 3.12 (Advanced settings).
3. In Advanced settings -> Secrets, paste: GROQ_API_KEY = "your_key_here"
4. Deploy.

Never upload your real API key to GitHub.
